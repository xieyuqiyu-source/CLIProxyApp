# CLIProxyApp

`CLIProxyApp` 是独立的客户端开发仓库，用于承载你自己的 CLIProxy 客户端实现。

## 仓库定位

- 这是实际开发和提交代码的仓库
- 官方项目更新不在本仓库内维护
- 本地默认配合同级目录中的 `CLIProxyApi` 与 `CLIProxyManagement` 使用

## 本地工作区关系

```text
CLIProxy/
├── CLIProxyApi/
├── CLIProxyManagement/
└── CLIProxyApp/
```

## 相关项目

- 官方文档：<https://help.router-for.me/>
- 服务端：`../CLIProxyApi`
- 管理界面：`../CLIProxyManagement`

## 当前状态

当前仓库已完成初始化，后续可在此基础上继续搭建：

- Web 客户端
- Electron 客户端
- Tauri 客户端
- Hybrid 客户端
