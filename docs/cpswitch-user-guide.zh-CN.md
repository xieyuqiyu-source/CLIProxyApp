# CPSwitch 用户使用指南

CPSwitch 是一个桌面代理工具。安装并登录后，它会在本机启动代理服务，帮助你获取可用账号、查看额度，并把代理接入 Codex、Continue、OpenClaw、Kiro 等工具。

这份文档只面向普通用户，按实际使用流程说明。

## 1. 下载应用

打开官网：

```text
https://cliproxy.szxsai.com/
```

根据系统选择安装包：

- Windows：点击 `下载 Win`。
- macOS：鼠标悬浮 `下载 Mac`，再选择对应处理器。
- Apple 芯片：适用于 M1、M2、M3、M4 等 Mac。
- Intel 芯片：适用于 Intel 处理器 Mac。

下载后按系统提示安装，然后打开 `CPSwitch`。

## 2. 登录或注册

打开应用后，先登录账号。

如果你还没有账号：

1. 点击 `注册账号`。
2. 输入邮箱和密码。
3. 根据提示完成验证码验证。
4. 注册成功后回到登录页登录。

登录时可以勾选 `信任本机 7 天`。勾选后，下次打开应用会自动尝试登录。

## 3. 认识主界面

登录成功后，你会看到一个简洁的小窗界面。

顶部会显示：

- 当前账号
- 本地代理状态
- 当前套餐
- 到期时间

常用按钮：

- `获取账号`：从共享号池获取可用账号。
- `OpenClaw`：把当前代理接入 OpenClaw。
- `Kiro反代`：开启 Kiro / 9router 反代。
- `开通会员`：购买或升级套餐。
- `OpenAI兼容`：添加自己的 OpenAI 兼容接口。
- `Codex配置`：让 Codex 使用 CPSwitch 代理。
- `Continue配置`：让 Continue 使用 CPSwitch 代理。

如果顶部状态显示 `运行中`，说明本地代理已经可用。

## 4. 获取账号

点击 `获取账号` 后，CPSwitch 会自动从共享号池同步账号到本地。

不同套餐可获取的账号数量不同：

- 免费用户：不能使用共享号池。
- Pro：可获取一组共享账号。
- Pro Max：可获取更多共享账号。

获取成功后，账号会出现在下方卡片里。共享账号会用 `共享账号` 样式标识，方便和你自己的账号区分。

## 5. 查看额度

主界面下方是额度卡片。

你可以通过上方标签筛选：

- 全部
- Codex
- Claude
- Gemini CLI
- Antigravity
- Kimi

额度卡片通常会显示：

- 当前账号
- 账号状态
- 套餐类型
- 5h 额度
- 1week 额度或其他周期额度

卡片右上角的刷新按钮可以刷新当前账号额度。  
如果额度暂时没有显示，点击刷新后等待一会儿。

## 6. 登录自己的模型账号

如果你想使用自己的模型账号，可以在额度区域点击 `登录账号`。

弹窗里有三种方式：

### OAuth

适合网页授权登录。选择对应服务后，按提示完成授权。

当前 OAuth 入口包括：

- Codex
- Claude
- Gemini
- Grok / xAI

### Token/Json

适合你已经有 token 或认证 JSON 的情况。

可以粘贴：

- session JSON
- auth.json
- Sub2API JSON
- accessToken
- access_token
- refreshToken
- refresh_token

如果你粘贴的是完整 JSON，应用会自动按 JSON 导入。  
如果你粘贴的是纯 token，需要在下方选择账号类型和 token 类型，然后点击 `识别并导入认证`。

### 导入

适合你手上已有 `.json` 认证文件。

点击 `选择 JSON 文件`，选中文件后应用会自动导入。

导入成功后，账号会出现在额度卡片里。

## 7. 开通会员

点击 `开通会员` 可以选择套餐。

套餐通常包括：

- Pro
- Pro Max

可选周期：

- 月付
- 半年付
- 年付

选择套餐后，使用微信扫码支付。支付成功后，应用会自动刷新会员状态。  
如果没有立刻刷新，可以等待几秒，或重新登录一次。

## 8. 配置 Codex

点击 `Codex配置`，可以让 Codex 使用 CPSwitch 的本地代理。

一般流程：

1. 打开 `Codex配置`。
2. 选择需要使用的模型。
3. 确认写入配置。
4. 重启 Codex 或重新打开相关窗口。

如果配置页没有显示 baseURL，通常说明配置还没有生效。重新选择并确认一次即可。

## 9. 配置 Continue

点击 `Continue配置`，可以把 CPSwitch 代理写入 Continue。

写入后建议重启 Continue，确保新配置生效。

## 10. 添加 OpenAI 兼容接口

点击 `OpenAI兼容`，可以添加自己的 OpenAI 格式接口。

你通常需要准备：

- 请求地址 baseURL
- API Key
- 模型名称

保存后，这个接口就可以被 CPSwitch 本地代理使用。

## 11. 接入 OpenClaw

点击 `OpenClaw` 后，应用会读取当前代理模型，并帮你写入 OpenClaw 配置。

推荐使用 `新版` 模式：

1. 点击 `OpenClaw`。
2. 选择 `新版`。
3. 勾选要写入的模型。
4. 选择默认模型。
5. 需要时选择备选模型。
6. 点击 `继续`。
7. 等待日志显示完成。

完成后，重启或重新打开 OpenClaw 即可使用。

## 12. 使用 Kiro 反代

点击 `Kiro反代` 会打开 Kiro 反代窗口。

点击 `开启反代` 后，应用会自动：

1. 检查 9router。
2. 安装缺失的 9router。
3. 启动本地反代。
4. 生成请求地址。
5. 生成 API Key。

完成后，复制窗口里的：

- 地址
- API Key

把它们填到需要使用反代的工具里即可。

你也可以点击 `探查模型`，查看当前反代可用的模型列表。

## 13. 配合 CCSwitch 使用

Kiro 反代窗口里提供了 CCSwitch 官网和下载入口。

在 CCSwitch 中可以这样配置：

1. 选中你想使用反代的工具，例如 ClaudeDesktop。
2. 点击右侧黄色 `+` 号。
3. 选择自定义配置。
4. 下滑到底，其他内容可以随便填。
5. 填入 CPSwitch 显示的请求地址和 API Key。
6. 开启模型映射。
7. 获取模型列表。
8. 选择需要使用的模型。
9. 添加并启用。
10. 重启目标应用后使用。

## 14. 应用更新

CPSwitch 登录后会自动检查更新。

如果发现新版本：

1. 点击确认更新。
2. 等待下载进度完成。
3. 下载完成后按提示打开安装包。
4. 安装新版本。

macOS 会根据电脑处理器下载对应版本：

- Apple 芯片下载 aarch64 版本。
- Intel 芯片下载 x64 版本。

## 15. 常见问题

### 登录失败

检查邮箱和密码是否正确。  
如果之前开启过信任本机但自动登录失败，重新手动登录一次。

### 提示连不上服务端

先确认网络正常。也可以打开下面地址检查服务是否可用：

```text
https://cliproxy.szxsai.com/healthz
```

正常会显示：

```json
{"status":"ok"}
```

### 获取账号失败

常见原因：

- 当前套餐不支持共享号池。
- 本地代理还没有启动完成。
- 云端暂时没有可用共享账号。
- 已获取的账号还没有用完，暂时不能重新获取。

### 额度没有显示

可以尝试：

1. 点击卡片右上角刷新。
2. 切换到对应模型标签。
3. 等待几秒后再刷新。
4. 确认认证文件已经导入成功。

### Codex 配置后没生效

确认配置页里能看到 baseURL。  
如果没有显示 baseURL，重新选择模型并确认写入，然后重启 Codex。

### OpenClaw 配置后没生效

尝试：

1. 确认 CPSwitch 状态为 `运行中`。
2. 重新执行 OpenClaw 接入。
3. 重启 OpenClaw。
4. 如果模型混乱，可以在新版模式里清理旧模型。

### Kiro 反代启动失败

常见原因：

- 本机没有 Node.js / npm。
- npm 安装 9router 失败。
- 端口被占用。
- 网络无法连接 npm。

可以先确认网络，再重新点击 `开启反代`。

### macOS 提示无法打开应用

确认下载了正确处理器版本。  
如果系统拦截应用，在 macOS 系统设置里允许打开即可。

## 16. 推荐使用流程

日常使用可以按这个顺序：

1. 打开 CPSwitch。
2. 登录账号。
3. 确认状态为 `运行中`。
4. 点击 `获取账号`。
5. 查看额度卡片。
6. 配置 Codex、Continue、OpenClaw 或 Kiro。
7. 在目标工具里开始使用。
